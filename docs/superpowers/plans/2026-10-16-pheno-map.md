# Pheno-map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, deep-linkable website mapping SM collider processes across all colliders. For each observable it shows what has been measured, what theory has achieved (including amplitude building blocks), and a referenced uncertainty budget. Every datum carries a provenance and verification status.

**Architecture:**
- **Data as code.** The data lives as YAML in `data/` and is validated by JSON Schema plus integrity checks in Python.
- **Build.** A Python build derives the matrix metrics, reverse indices and search index, then writes a single `site/data.json`.
- **Frontend.** `site/` is a framework-free ES-module frontend that uses D3 for the matrix, scatter and stacked bars, with hash routing.
- **GitHub.** GitHub Actions run CI and deploy to Pages. A separate workflow turns user ✓/⚑ issues into auto-merged, status-only PRs.
- **Agents.** Agent drafting and monitoring are repo-local Claude Code commands that the owner triggers manually.

**Tech Stack:** Python ≥3.12 (`ruamel.yaml`, `jsonschema`, `pytest`; HTTP via stdlib `urllib`), vanilla JS ES modules + D3 7.9.0 (cdnjs), Node ≥20 built-in test runner for pure JS modules, GitHub Actions/Pages, Zenodo.

**Spec:** `pheno-map/DECISIONS.md` (decisions #1–#22). The repo root is `pheno-map/`, and all paths below are relative to it.

## Global Constraints

- Everything lives in `pheno-map/`, which is the git repo root (#3). Licences: code MIT (`LICENSE`), data CC-BY-4.0 (`data/LICENSE`) (#19).
- Sector: every family and process has `sector`, and only `SM` is allowed for now; the enum is extended later for BSM (#2, #22).
- Families, in this order and with these ids (#10): `fam:vector-bosons` Vector bosons · `fam:top` Top quark · `fam:higgs` Higgs · `fam:jets-alphas` Jets & αs · `fam:ee-hadronic` e⁺e⁻ hadronic · `fam:ew-precision` EW precision · `fam:photons` Photons · `fam:heavy-flavour` Heavy-flavour production · `fam:dis` DIS.
- ID prefixes (#14): `fam:` `proc:` `chan:` `meas:` `obs:` `amp:` `par:` `col:`.
  - Pattern: `^(fam|proc|chan|meas|obs|amp|par|col):[a-z0-9][a-z0-9./+-]*$`.
  - IDs never change. A renamed node keeps its old ID in `aliases: [..]`.
- Ref formats (#14), with these regexes:
  - `inspire:<digits>`
  - `arXiv:<NNNN.NNNNN|old-style>`
  - `hepdata:ins<digits>/<table name>`
  - `arXiv:<id>, <locator>` for figures
- Experimental uncertainty categories (#11): `stat lumi energy_scale efficiency unfolding_model background acceptance_extrapolation beam pileup other`. `other` triggers a build **warning**.
- Theory uncertainty categories (#11): `MHOU PDF alphas parametric nonpert matching_shower EW_missing approximation numerical`.
  - `method` is required for `MHOU`, `nonpert` and `matching_shower`.
  - `pdf_set` is required for `PDF`.
- Status ladder (#17): `agent-draft | cross-checked | machine-verified | human-verified | disputed`. Source: `hepdata | agent | human`.
- Provenance record, required on every datum (#6, #17): `{uid, ref, locator, source, status, date, verified_by?, issue?}`.
  - `uid` is 8 lowercase hex characters and unique across the repo.
  - `locator` is a non-empty string. **A numeric value without a locator is a build error.**
- Size encoding (#12): `size: {range: [min, max], unit: "%" (default; any other unit must be explicit), asymmetric: bool, regions?: [{where, value}]}`.
  - A region `value` is a string such as `"±0.4"` or `"+3.1/−5.0"`; both ASCII `-` and U+2212 are accepted.
- QCD/EW order enum (#13): `LO NLO NNLO N3LO N4LO`.
  - Resummation is a **list** of `{accuracy, variable}`, e.g. `{accuracy: "N3LL'", variable: qT}`.
- Building-block rows (#5): `NLO QCD`, `NNLO QCD`, `N3LO QCD`, `NLO EW`, `NNLO EW`, `NNLO QCD×EW`.
  - Columns, fixed (#9): `born 1L 2L 3L RV RR RRR ir_scheme code`.
  - Cell status: `done | partial | missing`.
- Coverage: `complete | partial | stub` (#16). Staleness: `today > last_reviewed + 18 calendar months` (#18). Verifier account age: ≥ 6 calendar months (#17).
- Projections (#15): `projected: true` requires `projection_source: {ref, date}`. HL-LHC is its own collider column, `col:lhc-hl`.
- Hierarchy interpretation (#4 + #21):
  - A channel holds `measurements` (dataset-level metadata) and `observables`.
  - Each observable has `results: [{measurement: meas:…, total, uncertainties}]`.
  - So the Measurement level is kept, and one observable page lists all its measurements (#21).
- Derived values are never stored in YAML (#13). This covers: cell QCD order, precision ratio, process-level status, amplitude↔prediction reverse links, family stats, staleness.
- Precision ratio = headline prediction `total.value_pct` ÷ smallest `total.value_pct` among the headline observable's results.
  - Superseded and preliminary results are excluded.
  - Projected results are excluded unless the "include projections" toggle is on.
  - The ratio is `null` when either side is missing, and the cell is then hatched (#8, #15).
- Hosting: `github.com/pheno-map/pheno-map`, served under `/pheno-map/`.
  - Every site URL is relative, and routing is `location.hash = "#/" + id` (#20).
  - D3 loads only from `https://cdnjs.cloudflare.com/ajax/libs/d3/7.9.0/d3.min.js`.
- Agents never write a number from memory: each must be fetched from the source named in `ref`/`locator` (#17). No scheduled automation; the owner triggers every agent run (#18).

## Review Focus

1. **Physics notation in search and display** (`γ*`, `ℓℓ`, `N3LL′`, `√s`, `αs`). Typing `gamma`, `N3LL'` or `alphas` must find the entry. Pinned in Task 13.
2. **Sparse channels** (`coverage: stub`, no observables, no headline, no predictions). The build must not crash, `max_qcd`/`ratio` must be `null`, and the matrix must draw a hatched cell. Pinned in Tasks 5 and 11.
3. **Dangling and renamed IDs.**
   - A `compared_to`, `uses_amplitudes`, `superseded_by`, `headline` or `also_in` that points nowhere fails the build, with a message naming the file and the ID.
   - Two nodes claiming the same alias also fail the build.
   - An old alias in a URL lands on the new page, and an unknown hash shows "not found".
   - Pinned in Tasks 3 and 10.
4. **Region and total strings** with Unicode minus, `±`, asymmetric `+a/−b`, or a missing sign. They must parse into `{up, down}`, and anything else must fail validation rather than render `NaN`. Pinned in Tasks 2 and 12.
5. **Malformed verification issues**: an unknown `uid`, an account younger than 6 months, a user re-verifying their own verification, a flag on an already disputed datum, or an edited issue body. The workflow must comment and close the issue without editing data, except for a flag on a disputed datum, which only adds the issue link. Pinned in Task 15.

Process schema shape, which the implementer encodes exactly:
```yaml
id, name, family, also_in?: [fam], sector: SM, aliases?: [id], description?
watch?: {recids: [int], queries: [str], last_run?: date}
building_blocks?: [{row: <row enum>, cells: {<column enum>: {status, approximations?: [str], amplitude?: amp-id, refs?: [ref], provenance}}}]
channels: [{
  id, collider: col-id, initial_state: str, coverage, last_reviewed: date, aliases?,
  headline?: {observable: obs-id, region: str},
  measurements?: [{id, experiment: str ("combination" allowed), dataset: str, ref, hepdata?: ref,
                   projected?: bool, projection_source?: {ref, date}, assumptions?: str,
                   superseded_by?: meas-id, preliminary?: bool, aliases?}],
  observables?: [{
    id, name, kind: total|fiducial|differential|ratio|asymmetry|pseudo, variable?: str, aliases?,
    results?: [{measurement: meas-id, total: Total, uncertainties: [UncertaintyExp]}],
    predictions?: [{label, accuracy: Accuracy, codes?: [str], uses_amplitudes?: [amp-id],
                    total?: Total, uncertainties?: [UncertaintyTh], compared_to?: [meas-id],
                    refs: [ref], provenance, headline?: bool}],
    resummation_ingredients?: [{name, status, refs, provenance}],
    theory_target?: {required_total: str, current_total?: str, source: ref, provenance}
  }]
}]
```
Here `Total = {value_pct: number ≥ 0, provenance}`. `Accuracy = {qcd: order, ew?: order, mixed?: str, resummation?: [{accuracy, variable}], shower_matched?: bool, approximations?: [str]}`. Amplitude: `{id, process, loops: int, corrections: QCD|EW|mixed, status, approximations?, master_integrals?: {status, refs}, refs, provenance, aliases?}`. Parameter: `{id, name, symbol, unit, aliases?, determinations: [{value: number, uncertainty: number, extracted_from: [obs-id|meas-id], ref, provenance}]}`.

### Task 8: Link check and HEPData ingestion

**Files:**
- Create: `scripts/linkcheck.py`, `scripts/phenomap/hepdata.py`, `scripts/ingest_hepdata.py`, `data/hepdata_label_map.yaml`
- Create: `tests/test_hepdata.py`, `tests/fixtures/hepdata/table.yaml`

**Interfaces:**
- Produces: `linkcheck.main(argv) -> int`.
  - It HEAD/GETs every resolved INSPIRE recid, every arXiv `https://arxiv.org/abs/<id>`, and every HEPData table URL.
  - It reports failures and exits 1 on any failure. It is run manually and in CI on PRs that touch `data/`.
- Produces: `fetch_table(recid: int, table: str, version: int = 1) -> dict`, via `https://www.hepdata.net/download/table/ins<recid>/<url-quoted table>/<version>/yaml`. Confirm the URL form against one live record in Step 3, and adjust only this function if it differs.
- Produces: `summarize(table: dict, label_map: dict) -> list[dict]`. It returns Q10/Q11 `uncertainty_exp` dicts:
  - `range` is the min and max over bins of `|err|/|value|·100`, rounded to 2 significant figures, taking the max of `|plus|` and `|minus|` for asymmetric errors
  - `asymmetric` is set when any bin has `plus ≠ −minus`
  - `full_table` is `hepdata:ins<recid>/<table>`
  - provenance is `{source: hepdata, status: machine-verified, locator: "<table>, error '<label>'"}`
  - unmapped labels go to `other`
- Produces: `total_pct(table, region_bin: int | None) -> float`, the quadrature sum at the given bin, or the minimum over bins.
